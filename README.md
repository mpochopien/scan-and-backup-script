# BACKUP AND PC SCAN SCRIPT

Toolset for backup and PC scan:
1) upgrades software using winget
2) cleans Windows TMP directory
3) scans PC for malware and adware using AdwCleaner and MS Defender
4) backs up files and folders
5) turning off PC and/or offline scan using MS Defender

## Getting Started

1) Create `settings.json` based on `settings.example.json`
2) Install dependencies `pip install -r requirements.txt`
3) Run `start.py`
